# Release Notes 0.21.0

Optionale, standardmäßig deaktivierte ZKTeco-SC800-PUSH-Anbindung mit sicherem Enrollment, Mitarbeiter-/RFID-Zuordnung, idempotenter Ereignisinbox, chronologischer Offline-Nachlieferung, Adminstatus und konservativem ATTLOG-Emulator. Migration 25 ergänzt Terminalmetadaten und legt `terminal_identities`, `terminal_cards` und `terminal_events` datenerhaltend an. Nicht verifizierte ausgehende SC800-Kommandos bleiben bewusst deaktiviert. Details: `docs/ZKTECO_SC800.md` und `docs/ZKTECO_SC800_COMPATIBILITY.md`.

Diese technische Erweiterung ist weder eine Aussage über die vollständige Rechtskonformität noch eine Zertifizierung der Anwendung oder Hardware.
