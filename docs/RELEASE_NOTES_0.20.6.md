# Release Notes 0.20.6

Version 0.20.6 korrigiert die Bedienung des Abwesenheitskalenders und strukturiert die Benutzerverwaltung neu.

- Persönlicher und Teamkalender markieren ausschließlich den gewählten Reiter.
- Eine Monatswahl lädt sofort; in der Wochenansicht bestimmt sie die angezeigte Woche und bleibt bei der Navigation erhalten.
- Monatsüberschriften verwenden immer deutsche Monatsnamen.
- Versionierte Arbeitszeitpläne werden in einem responsiven, tastaturbedienbaren Modal verwaltet.
- Die Benutzerdeaktivierung trennt Begründung, Folgen und Aktion und erläutert den vollständigen Erhalt gesetzlicher Nachweisdaten.

## Datenbank und Migration

Das Datenbankschema bleibt unverändert. Migration 23 wird nicht verändert; eine neue Migration ist nicht erforderlich.
